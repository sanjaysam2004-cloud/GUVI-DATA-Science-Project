NYC 311 Complaint Data Analysis

Project Overview

This project analyzes NYC 311 complaint data to understand complaint patterns, borough-wise distribution, complaint types, and resolution time.

Objectives

- Analyze NYC 311 complaint records.
- Clean and preprocess raw data.
- Handle missing values and duplicate records.
- Perform Exploratory Data Analysis (EDA).
- Analyze complaint status and resolution time.
- Visualize important trends and patterns.
- Perform SQL-based data analysis.

Tools & Technologies

- Python
- Pandas
- Matplotlib
- MySQL
- SQL
- Jupyter / Python

Project Workflow

1. Data Collection
2. Data Cleaning
3. Data Preprocessing
4. Exploratory Data Analysis
5. Data Visualization
6. SQL Analysis
7. Insights and Results

Key Analysis

- Borough-wise complaints
- Top 10 complaint types
- Monthly complaint trends
- Missing values analysis
- Correlation heatmap
- Resolution time analysis
- Complaint status analysis

Conclusion

This project helps understand NYC 311 complaint patterns through Python, SQL, data cleaning, exploratory data analysis, and visualization.
